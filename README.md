# 🚆 Train Reservation System (C Project)

This is a **C language-based project** that simulates a train ticket booking system. The program allows users to select seat type, class, and input passenger details. It then allocates a seat and calculates the ticket fare accordingly.

---

## 📌 Features

- 🚉 Train ticket booking interface  
- 🪑 Seat and class selection (Sleeper, AC, etc.)  
- 🧑 Passenger details entry  
- 💸 Fare calculation  
- 🧾 Ticket generation  
- ❌ Booking cancellation  
- 📃 Summary of booked tickets
